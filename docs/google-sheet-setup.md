# 網站內容 Google Sheet：設定與更新方式

網站上的「Jason 親選」與「最多人收聽」由這份 Google Sheet 管理，不需要寫程式。
網站每天凌晨 3:00（台北時間）自動讀取一次；急著上線時，可請 Annie 在 GitHub 按「Run workflow」立即更新。

## 一次性設定（約 10 分鐘）

1. 建立新的 Google Sheet，命名為「Jason好好聊 網站內容」。
2. 建立兩個分頁，名稱必須完全一致：
   - `Jason親選`
   - `最多人收聽`
3. 匯入範本（第一列是欄位名稱，請勿修改）：
   - 檔案 → 匯入 → 上傳 `data/sheets/jason-picks.csv` → 「取代目前的工作表」（在 `Jason親選` 分頁）
   - 檔案 → 匯入 → 上傳 `data/sheets/most-listened.csv` → 「取代目前的工作表」（在 `最多人收聽` 分頁）
4. 鎖住第一列：選取第 1 列 → 資料 → 保護工作表和範圍 → 僅限自己編輯。
5. 「顯示」欄加下拉選單：選取 D 欄 → 資料 → 資料驗證 → 下拉式清單 → `✓`、`✗`。
6. 發布為 CSV：檔案 → 共用 → 發布到網路 → 選擇分頁 → 格式選「逗號分隔值 (.csv)」→ 發布。
   兩個分頁各做一次，把兩個連結傳給 Annie（貼到 `data/sheets.json`）。

> 發布後，持有連結的人都能看到這兩個分頁的內容。這兩個分頁只放**網站上本來就會公開**的資訊，請勿放聯絡方式、電子郵件或內部備註。

## 欄位說明

### Jason親選

| 欄位 | 填寫方式 |
|---|---|
| EP | 集數號碼，例如 `247` |
| 推薦理由 | Jason 的一句話推薦（空白時網站顯示「推薦理由待補」） |
| 順序 | 1、2、3…，決定顯示順序；網站只顯示最前面的 3 集 |
| 顯示 | `✓` 顯示、`✗` 暫時隱藏 |
| 備註 | 內部備註；若寫「暫定」，網站會標示「暫定，待 Jason 確認」 |

### 最多人收聽

| 欄位 | 填寫方式 |
|---|---|
| 排名 | 1、2、3…；網站只顯示前 3 名 |
| EP | 集數號碼 |
| 來源 | 例如 `SoundOn`、`YouTube` |
| 期間 | 例如 `全部`、`2026-10`、`近 90 天`（可空白） |
| 更新日期 | 例如 `2026-10-21` |

建議每月從 SoundOn 後台「綜合平台數據」依下載數排序，更新前 3–10 名。

## 填錯了會怎樣？

網站更新前會先檢查每一列（集數存在嗎？數字是數字嗎？「顯示」是 ✓/✗ 嗎？）。
只要有一列有問題，**網站會繼續顯示上一版正確的內容**，不會壞掉；Annie 會在更新紀錄看到是哪一列需要修正。
